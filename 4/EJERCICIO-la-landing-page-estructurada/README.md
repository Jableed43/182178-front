# Ejercicio: La landing page estructurada

**Clase 04 — HTML Semántico + Formularios + Multimedia** · Frontend
*(en la cursada es la clase 5)*

El ejercicio de la clase: una página de aterrizaje para un consultorio que junta las tres
cosas vistas — semántica estricta, multimedia y un formulario.

La consigna paso a paso está en `pasos.md`. En `solucion/` está el `index.html` terminado,
para comparar **después** de intentarlo.

## Qué se entrega

El `index.html`. Si ya tienen el repositorio de la clase pasada, va ahí, en una rama propia:
es la excusa para repasar `git switch -c` y el merge.

## El criterio de corrección

- Ningún `div` en el esqueleto: `header`, `main`, `footer`.
- La presentación en `article`, el contacto en `section`.
- Dos `iframe` con su `title`.
- Cada `input` con su `label` vinculado y con `name`.
- Los dos radios con el mismo `name`.

## Carpetas

- `fuente/` — el archivo con los huecos y la consigna.
- `inicio/` — lo mismo, con los `TODO` a completar.
- `solucion/` — la página terminada.
