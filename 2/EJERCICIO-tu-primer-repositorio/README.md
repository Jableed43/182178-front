# Ejercicio: Tu primer repositorio

**Clase 02 — Git y GitHub: El flujo de trabajo profesional** · Frontend

Demostrá que controlás el flujo básico del control de versiones, de la terminal a la nube.

## Consignas

1. Abrí Git Bash o la terminal de VS Code (`Ctrl + ñ`) y creá la carpeta `mi-primer-repo`.
2. Entrá a la carpeta y corré `git init`.
3. Creá un `index.html` básico, con el boilerplate de la clase anterior.
4. Mirá `git status` (el archivo aparece en rojo), pasalo con `git add .` y volvé a mirar (verde).
5. Sacá la foto con `git commit -m "chore: initial commit"`.
6. Creá un repositorio vacío en GitHub y copiá sus tres comandos para hacer tu primer `git push`.

## Cómo se corre

El ejercicio **no se hace dentro de esta carpeta**: se hace en una carpeta nueva
llamada `mi-primer-repo`, afuera. Acá están el `index.html` para versionar y los
pasos escritos.

## Qué debería verse

`git log --oneline` muestra un commit tuyo, y el repositorio en GitHub muestra el
`index.html`. Ese es el entregable: el enlace a tu repositorio.

## Carpetas

- `inicio/` — el `index.html` y `pasos.md` con los huecos `TODO (Ejercicio)`.
- `solucion/` — los mismos pasos con todos los comandos escritos, para comparar.
- `fuente/` — igual que la solución, con las marcas de hueco.
